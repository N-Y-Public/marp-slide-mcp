# ページタイトル

中見出し（セクションディバイダー）の目的と課題解決

## ページ主張

- 長大なスライド資料における現在地の明確化と構成の可視化を実現
  - ページ数の多いプレゼンテーションでも聴衆の集中を維持し論理構造を明示

### 主張補足タイトル

背景と解決アプローチ

#### 本文

- **課題**: 30ページを超える長大な資料では、現在のスライドが全体のどの章・文脈に位置するのか見失いやすい
- **解決策**: 章の区切りとなる4種類の中見出し（セクションディバイダー）スライドを標準テンプレートとして提供
  - `title-only`: 章タイトルのみを大きく表示する標準的な区切り
  - `title-and-pages`: 章タイトルと章内のページ一覧・アンカーリンクを表示
  - `all-chapters`: 全章一覧の中でカレント章を太字強調、他章を薄色（dim）表示
  - `all-chapters-and-pages`: 全章一覧とカレント章配下のページリンクを複合表示

図表出典：Issue #17 / PBI-020 要求仕様書

# ページタイトル

データ構造とZodスキーマ定義

## ページ主張

- MCPサーバーの全スライド操作ツールで型安全に中見出しを指定可能
  - `generate_slide_deck`、`insert_slide`、`update_slide` の共通スキーマとして統合

### 主張補足タイトル

`SectionDividerSchema` のデータ構造

#### 本文

```typescript
// 中見出しスライド定義スキーマ (DAT-TYP-010)
export const SectionDividerSchema = z.object({
  pattern: z.enum(["title-only", "title-and-pages", "all-chapters", "all-chapters-and-pages"]),
  chapterTitle: z.string().describe("章のタイトル（例: '第1章 プロジェクト概要'）"),
  chapterPages: z.array(SectionPageItemSchema).optional().describe("章配下のページ一覧"),
  allChapters: z.array(z.string()).optional().describe("全章のタイトル一覧"),
  currentChapterIndex: z.number().int().optional().describe("カレント章のインデックス"),
});
```

- 既存の `NormalSlideSchema` に `sectionDivider?: SectionDividerSchema` としてオプショナル追加
- 既存スライド定義への完全な後方互換性を担保

# ページタイトル

CSSスタイリングとカレント章の強調

## ページ主張

- 聴衆へ認知負荷を与えずに全体の進行状況と現在地を直感的に伝達
  - カレント章を太字・プライマリカラーで強調し、他章は透過（dim）スタイルを適用

### 主張補足タイトル

ビジネステーマスタイル拡張仕様

#### 本文

- **上下中央垂直配置**:
  - `section.section-divider`: flexbox による縦方向中央寄せ（`justify-content: center`）
- **不要要素の自動非表示**:
  - 中見出しスライドでは不要となる主張バー（`h2`）、図表タイトル（`h3`）、図表出典（`h5`）を非表示化
- **コントラスト設計**:
  - `.active-chapter`: 太字かつ明瞭なフォントウェイトで現在地を強調
  - `.dim`: `opacity: 0.45` または薄色カラーで他章を目立たせず背景化

# ページタイトル

章別目次モード（toc-chapters-only）の仕組み

## ページ主張

- 目次スライドを章単位のハイレベルアジェンダに集約可能
  - 通常スライドの細かなタイトルを自動除外し、中見出しタイトルのみを抽出して目次を構築

### 主張補足タイトル

`marpTocPlugin` の抽出フィルタリング論理

#### 本文

- **通常目次モード (`<!-- _class: toc -->`)**:
  - 中見出しスライドを除外し、各スライドの `h1` 見出し（タイトル）を抽出して目次を生成
- **章別目次モード (`<!-- _class: toc toc-chapters-only -->`)**:
  - `section-divider` クラスを持つ中見出しスライドの章タイトルとページ番号のみを抽出
  - 長大なデッキでもアジェンダが1〜2ページに整然と収まり、エグゼクティブサマリーに最適

図表出典：marp.config.js (FN-ENG-001 marpTocPlugin)
